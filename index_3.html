Tournament Rules & Tiebreaker Criteria
Standing Display Order
  • Games Played (GP) — most games played ranks higher
  • Games Won (W) — most wins ranks higher
  • Win Points — 2 points for every win, 0 for a loss
  • Point Differential — total points scored minus total points given up
Two-Way Tiebreaker (2 teams tied)
  • #1 Head-to-Head: If the tied teams played each other in the league round, the winner ranks ahead.
  • #2 Point Differential: If #1 is not applicable, the team with the higher point differential from all league games ranks ahead.
  • #3 Chit Drawing: If still tied, a chit drawing will determine ranking.
Three-Way Tiebreaker (3+ teams tied)
  • #1 Head-to-Head (conditional): Only applies if one team has played ALL other tied teams and won or lost all those games. That team ranks first (all wins) or last (all losses).
  • #2 Point Differential: If #1 is not applicable, the team with the higher point differential from all league games ranks ahead.
  • #3 Chit Drawing: If still tied, a chit drawing will determine ranking.
General Notes
  • Tiebreaker rules may overwrite the online standings display if applied manually by the tournament committee.
  • All league round results are final once confirmed by both team coaches.
  • Playoff bracket seeding is determined after all league games are complete.
